# AuraAI Kazakhstan — Модуль машинного обучения (`ml_pipeline`)

Реальное ML-ядро прогнозирования приземной концентрации мелкодисперсных частиц **PM2.5** в городах Казахстана для республиканского конкурса **GREENHACK KAZAKHSTAN 2026** (направление: *Искусственный интеллект и инженерия данных*).

---

## 1. Структура модуля

```text
ml_pipeline/
├── train_model.py                  # Полный цикл генерации/калибровки данных, обучения и экспорта ансамбля
├── requirements.txt                # Зависимости Python (numpy, pandas, scikit-learn)
├── data/
│   └── kz_air_quality_dataset.csv  # 8 400 почасовых наблюдений по 6 городам РК
└── artifacts/
    ├── evaluation_metrics.json     # Протокол валидации на отложенной выборке (MAE, RMSE, R², Feature Importance)
    └── aura_gbm_model.js           # Скомпилированный ансамбль из 125 деревьев решений для инференса в браузере
```

---

## 2. Признаковое пространство (`FEATURE_COLUMNS`)

Модель обучается на 9 наблюдаемых метеорологических, временных, орографических и сценарных признаках:

| Признак | Ед. изм. | Физический смысл |
|---|---|---|
| `temperature` | °C | Температура воздуха на высоте 2 м (определяет интенсивность отопления при $T < +10^\circ\text{C}$) |
| `wind_speed` | м/с | Скорость ветра на высоте 10 м (горизонтальная турбулентная продуваемость) |
| `inversion_height` | м | Высота пограничного слоя / температурной инверсии («купол» запирания смога) |
| `humidity` | % | Относительная влажность воздуха (гигроскопический рост аэрозолей при $RH > 65\%$) |
| `hour_of_day` | 0..23 | Час суток (улавливает утренний 08:00 и вечерний 21:00 пики растопки угольных печей) |
| `is_weekend` | 0 / 1 | Индикатор выходного дня (снижение маятникового автомобильного трафика) |
| `coal_abatement_pct` | 0..100% | Доля перевода печей частного сектора на газ и метод верхнего розжига (*EcoHeat*) |
| `nmu_abatement_pct` | 0..100% | Степень разгрузки ТЭЦ, промзоны и транзита дизельных фур по протоколу НМУ-2 |
| `basin_trapping_idx` | коэфф. | Индекс орографического запирания котловины (Алматы `1.38`, Өскемен `1.32`, Астана `0.98`) |

---

## 3. Результаты валидации на отложенной выборке (Chronological Holdout 80/20)

Разбиение выполнено строго хронологически (`6 720` train / `1 680` test) без утечки данных из будущего:

| Архитектура модели | $R^2$ Score | MAE ($\text{мкг/м}^3$) | RMSE ($\text{мкг/м}^3$) | Комментарий |
|---|---:|---:|---:|---|
| `RidgeLinearBaseline` | `0.6040` | `21.29` | `29.33` | Линейная модель не способна уловить нелинейный эффект инверсии |
| `RandomForestRegressor` | `0.9301` | `8.51` | `12.32` | Высокая точность, но ступенчатая экстраполяция на краях |
| **`GradientBoostingRegressor` (AuraPredict)** | **`0.9709`** | **`5.63`** | **`7.96`** | **Основная модель продакшна (125 деревьев, max_depth=5)** |

---

## 4. Запуск переобучения и экспорта весов

```powershell
python ml_pipeline/train_model.py
```

Скрипт автоматически сохраняет обновленный датасет, метрики и компилирует все 125 деревьев решений в `ml_pipeline/artifacts/aura_gbm_model.js`, который напрямую подключается к ситуационной панели `index.html`.
